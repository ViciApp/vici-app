# Satellite reusability catalog

Search here before writing a helper in `src/satellite/`. Adding a shared one? Add its row in the same PR ([meta-update rule](../governance.md#meta-update-rule)). The satellite also reuses `#lib` constants, schemas, types and pure utils (see [`structure.md`](./structure.md#imports)); for those, search the [frontend catalog](../frontend/reusability.md).

## `src/satellite/utils/`

| File                        | Exports                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `candid.utils.ts`           | `candidMethod({ canister, method })`: the `argTypes` and `result` IDL types of a registry or clearing method, read off the generated factories. The only place outside `src/declarations` that may `import { IDL }`.                                                                                                                                                                                                                                                  |
| `logger.utils.ts`           | `logInfo`, `logError`: structured logging with stable string tags                                                                                                                                                                                                                                                                                                                                                                                                     |
| `regex.utils.ts`            | `escapeRegex(value)`, for building Juno `matcher` keys from user input                                                                                                                                                                                                                                                                                                                                                                                                |
| `time.utils.ts`             | `timeMs()`: the IC message time in milliseconds; use it for every `*Ms` stamp and window check instead of converting `time()` inline                                                                                                                                                                                                                                                                                                                                  |
| `tournament-draw.utils.ts`  | `tournamentDrawMonthRefusal({ monthAnchor, nowMs })`: the refusal reason for a draw outside the current UTC month (closed: `invalid_input`, not started: `month_not_started`), or nothing                                                                                                                                                                                                                                                                             |
| `tournament-prize.utils.ts` | `tournamentPodium(matches)`: the podium leagues once the final has a winner; `decideTournamentPrize(...)`: whether a caller earns a tournament prize and under which award key (memberships stored by the draw only, one prize per tournament, earlier per-place keys block); `isTournamentPrizeAwardKey(awardKey)`: the key shape `assertSetVxpAward` requires of a new prize                                                                                        |
| `vxp-payout.utils.ts`       | `transferErrorText(TransferError)`: the log text for a failed VXP ledger transfer                                                                                                                                                                                                                                                                                                                                                                                     |
| `wire-format.utils.ts`      | camelCase wire schemas (`j`) with a `Wire*` type and a `toWire*` converter for Profile, Relation, MarketTranslation, Referral, League, LeagueWithRole, LeagueMember, FriendRecommendedLeague, Battle, Affiliation, AffiliationStats, AffiliationMemberCount, AffiliationChampionship, Tournament, TournamentMatch, MonthlyLeaderboardEntry, BoldCallerEntry; `fromWireProfile` and `fromWireReferral` (also used by the frontend) fill the fields the wire leaves out |
| `worlds-podium.utils.ts`    | `joinedBeforeMonthClose({ joinedAtNs, monthAnchor })`: whether a Worlds slot joined at that (server-stamped) time may collect the month's podium prize                                                                                                                                                                                                                                                                                                                |

## Shared services

| File                               | Exports                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `services/authz.services.ts`       | `isAdmin({ caller })`, `getSeriesCreator(seriesId)`, `isCreatorOrAdmin(...)`: every caller-role check; `controllerCaller(purpose)`: the controller principal to pass as `caller` to the `*DocStore` APIs on a controllers-scoped collection (traps when there is none); `isControllerText(callerText)`: whether an assert's caller is a satellite controller |
| `services/engine-sync.services.ts` | the only mirror of Juno role docs into the icdc-core Vici engine                                                                                                                                                                                                                                                                                             |
| `services/vxp-awards.services.ts`  | `persistAward(...)`: creates the `pending` `vxp_awards` doc; `updateAward(...)`: records the `paid` / `failed` outcome at the version just read (no-op when the doc is missing). Used by the streak, achievement, comeback, league-founder and Flow award hooks                                                                                              |
| `services/vxp-payout.services.ts`  | `transferWithBadFeeRetry(...)`: the one VXP ledger transfer every award path uses                                                                                                                                                                                                                                                                            |
