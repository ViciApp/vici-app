# Satellite reusability catalog

Search here before writing a helper in `src/satellite/`. Adding a shared one? Add its row in the same PR ([meta-update rule](../governance.md#meta-update-rule)). The satellite also reuses `#lib` constants, schemas, types and pure utils (see [`structure.md`](./structure.md#imports)); for those, search the [frontend catalog](../frontend/reusability.md).

## `src/satellite/utils/`

| File                        | Exports                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `award-marker.utils.ts`     | `identityDigest(principalText)` (SHA-224 through `Principal.selfAuthenticating`: the one-way principal digest of an award marker), `vxpAwardMarkerKey(...)` / `vxpAwardMarkerPrefix(...)`, `VxpAwardMarkerType`                                                                                                                                                                                                                                                       |
| `candid.utils.ts`           | `candidMethod({ canister, method })`: the `argTypes` and `result` IDL types of a registry or clearing method, read off the generated factories. The only place outside `src/declarations` that may `import { IDL }`.                                                                                                                                                                                                                                                  |
| `logger.utils.ts`           | `logInfo`, `logError`: structured logging with stable string tags                                                                                                                                                                                                                                                                                                                                                                                                     |
| `regex.utils.ts`            | `escapeRegex(value)`, for building Juno `matcher` keys from user input                                                                                                                                                                                                                                                                                                                                                                                                |
| `time.utils.ts`             | `timeMs()`: the IC message time in milliseconds; use it for every `*Ms` stamp and window check instead of converting `time()` inline                                                                                                                                                                                                                                                                                                                                  |
| `tournament-draw.utils.ts`  | `tournamentDrawRefusal({ monthAnchor, nowMs })`: the refusal reason for a draw (`invalid_input` for a malformed anchor, a closed month or a current month whose round 1 window has closed; `month_not_started`), or nothing                                                                                                                                                                                                                                           |
| `tournament-prize.utils.ts` | `tournamentPodium(matches)`: the podium leagues once the final has a winner; `decideTournamentPrize(...)`: whether a caller earns a tournament prize and under which award key (memberships stored by the draw only, one prize per tournament, earlier per-place keys block); `isTournamentPrizeAwardKey(awardKey)`: the key shape `assertSetVxpAward` requires of a new prize                                                                                        |
| `vxp-payout.utils.ts`       | `transferErrorText(TransferError)`: the log text for a failed VXP ledger transfer                                                                                                                                                                                                                                                                                                                                                                                     |
| `wire-format.utils.ts`      | camelCase wire schemas (`j`) with a `Wire*` type and a `toWire*` converter for Profile, Relation, MarketTranslation, Referral, League, LeagueWithRole, LeagueMember, FriendRecommendedLeague, Battle, Affiliation, AffiliationStats, AffiliationMemberCount, AffiliationChampionship, Tournament, TournamentMatch, MonthlyLeaderboardEntry, BoldCallerEntry; `fromWireProfile` and `fromWireReferral` (also used by the frontend) fill the fields the wire leaves out |
| `worlds-podium.utils.ts`    | `joinedBeforeMonthClose({ joinedAtNs, monthAnchor })`: whether a Worlds slot joined at that (server-stamped) time may collect the month's podium prize; `worldsPodiumAwardKey({ monthAnchor, kind, place })`: the award key of one finish; `claimedWorldsPodiumAwardKeys(...)`: every key that counts as its claim, the older key without the kind included                                                                                                           |

## Shared services

| File                                     | Exports                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `services/authz.services.ts`             | `isAdmin({ caller })`, `getSeriesCreator(seriesId)`, `isCreatorOrAdmin(...)`: every caller-role check; `controllerCaller(purpose)`: the controller principal to pass as `caller` to the `*DocStore` APIs on a controllers-scoped collection (traps when there is none); `isControllerText(callerText)`: whether an assert's caller is a satellite controller; `assertControllerCaller({ caller, collection })` / `assertControllerWrite(context)`: the controller-only set or delete assert; `assertOwnerOrController({ caller, owner, collection })`: the owner-or-controller check every public-write assert uses |
| `services/engine-sync.services.ts`       | the only mirror of Juno role docs into the icdc-core Vici engine; `maySettle(caller)`: whether a caller may record a settlement activity (a controller or an oracle-settler role)                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `services/profile.services.ts`           | `decodeStoredProfile([key, doc])`: a `profiles` doc as every read reports it, its `owner` taken from the doc key; `withProfileRole({ profile, caller })`: `withProfileDefaults` plus the role that principal holds in `roles`. Every profile read (lookup, search, leaderboard, rival) goes through both                                                                                                                                                                                                                                                                                                            |
| `services/settled-history.services.ts`   | `settledTotalsByPrincipal(...)` / `settledTotals(...)`: members' settled calls and wins over a window from the clearing canister's `aggregate_settlement_accuracy`, the one source every accuracy-judged award reads (league battles, the Worlds podium, tournament matches)                                                                                                                                                                                                                                                                                                                                        |
| `services/leaderboard.services.ts`       | `refreshLeaderboardRankingFn()`: recompute the stored global ranking (`leaderboard_ranking`) from settled history unless it is fresh; `listLeaderboard()`, `getUserRankAndCountFn(...)`, `getMyRivalFn()` read that ranking, never `points`                                                                                                                                                                                                                                                                                                                                                                         |
| `services/school-registry.services.ts`   | `registryAdmits(...)`: whether a new school may take an id the `schools` registry holds (only on one of the row's domains); `claimSchoolRegistry(...)` / `recountSchoolRegistry(...)`: a verification creates a missing row and recounts its verified members, never rewriting the row's name, country, domains or an admin-set status                                                                                                                                                                                                                                                                              |
| `services/activity.services.ts`          | `countTradeActivities(caller)`: the caller's predictions (own `activities` rows keyed `#trade`), the one count the onboarding trade milestones and the referral first-prediction gate read                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `services/cohort.services.ts`            | `heldAffiliations({ caller, member?, kind? })`: each member's one affiliation per kind (the earliest-stored row when older data holds two), the row every Worlds reader, the podium and `assertSetAffiliation` go by                                                                                                                                                                                                                                                                                                                                                                                                |
| `services/league-member.services.ts`     | `leagueMemberPrincipals({ leagueId, caller, joinedBeforeMs? })`: a league's member principals, optionally only memberships stored before an instant (the doc's `created_at`); the members a league battle or tournament match is scored from                                                                                                                                                                                                                                                                                                                                                                        |
| `services/league-invite-cap.services.ts` | `resolveInviteCode({ callerText, inviteCode })`: the league a code opens for a caller; a code that opens none counts toward the caller's hourly cap (`LEAGUE_INVITE_MISSES_PER_HOUR`) in the controllers-only `league_invite_attempts` collection, and a caller past it is refused. The lookup preview and the join share it                                                                                                                                                                                                                                                                                        |
| `services/league-invite.services.ts`     | `leagueInviteCode(league)`: a league's invite code, for its members only; `leagueIdForInviteCode(code)`: the league a code opens; `recordLeagueInvite(...)` / `deleteLeagueInvite(...)`: the controllers-only `league_invites` store the create, join, disband and purge paths share                                                                                                                                                                                                                                                                                                                                |
| `services/vxp-award-markers.services.ts` | `recordAccountAwardMarkers(...)`: the account purge's marker per paid one-time award; `hasAwardMarker(...)` / `countAwardMarkers(...)`: what `assertSetVxpAward`, the onboarding payout and the league-founder cap read                                                                                                                                                                                                                                                                                                                                                                                             |
| `services/vxp-awards.services.ts`        | `persistAward(...)`: creates the `pending` `vxp_awards` doc; `updateAward(...)`: records the `paid` / `failed` outcome at the version just read (no-op when the doc is missing). Both sign as a satellite controller, the only writer `assertSetVxpAward` admits; every award path writes through them                                                                                                                                                                                                                                                                                                              |
| `services/vxp-payout.services.ts`        | `transferWithBadFeeRetry(...)`: the one VXP ledger transfer every award path uses                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
